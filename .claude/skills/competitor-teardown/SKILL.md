# Competitor and reference teardown

Adapted from irinabuht12-oss/marketing-skills `competitor-teardown` and
`competitor-creative-analysis` (MIT, see `.claude/THIRD_PARTY.md`).

Sources: their public profiles, the Meta Ad Library and Google Ads Transparency
Center (public). Cite only pages you opened, with dates.

For each account:
1. **Inventory**: active ads and recent posts by format (Reel, carousel, static, pin,
   talking head), message theme (pain, benefit, proof, urgency, humor), CTA, how often
   they post and refresh.
2. **What performs**: posts with unusually high views, saves, shares or comments; what
   the first 2 seconds do; caption length and style; sound type.
3. **Patterns across accounts**: conventions everyone follows (worth testing) and ones
   worth breaking on purpose.
4. **Gaps we can own**: messages no one is using that are true for Gamify (for example
   accessibility, privacy, one question set to many games).

Write the summary to `docs/marketing-lessons.md` (Competitor and reference teardowns),
using account type in anything public-facing. Never reuse their words, art, sounds,
characters or look; never name them in public content.
