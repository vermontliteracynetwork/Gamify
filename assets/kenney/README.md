# Kenney asset library (CC0)

Supplied by the teacher on 2026-10-31, all by Kenney (kenney.nl), released to
the public domain under CC0 (see LICENSE-CC0.txt): free for commercial use, no
credit needed (Gamify credits Kenney anyway on the Credits page).

- background-elements, background-elements-remastered: scenery (hills, trees,
  clouds, buildings) as SVG, for game backgrounds and theme starting points.
- game-icons: simple icon set (SVG).
- ui-pack: buttons, panels, sliders, checkboxes (SVG) in five colors.
- interface-sounds: clicks, confirmations, opens and closes (OGG).

In use: Cast and Catch fish and lake floor (public/classic/cast-catch, from the
Fish Pack) and the tap sound (public/sounds/tap.mp3).
