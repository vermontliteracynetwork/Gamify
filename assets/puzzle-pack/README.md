# Puzzle Games Graphics Pack (library copy)

Source: https://ci.itch.io/puzzle-games-graphics-pack, supplied by the teacher
on 2026-10-31 (Pipes, Extra Animals, and the main pack: animals, balls, blocks,
coins, gems, paddles, polyominoes, sweeper). Converted to 256px WebP here so
any game or theme can draw from it.

License: not yet confirmed (the itch.io page could not be opened from the
build session). Nothing here ships to students until the license is recorded
in docs/asset-ledger.md. In use on the work branch: Match Three gems
(public/classic/match-three) and Bubble Pop balls (public/classic/bubble-pop).
