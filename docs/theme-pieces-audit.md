# Theme pieces and power-ups audit (2026-10-27)

Every part of a listed game a theme can redesign, what was added in this
pass, and what stays drawn in code on purpose. Listed games only (teacher,
2026-10-26: question-interruption games for now).

| Game | Designable pieces | Added in this pass | Power-ups (Classic) | Still drawn in code, on purpose |
|---|---|---|---|---|
| Game Show | background, card back, grid square, team 1-10, trophy, cover | (power-ups, 2026-10-26) | Double Star, Swap Spinner, Sneaky Magnet, Prize Bag | Card faces after flipping (they show text) |
| Peg Drop | background, board, ball, peg, team 1-10, cover | bucket, big bucket | Golden Ball (drop x2), Prize Bag (bonus), Twin Ball (one more drop) | Drop zone arrows |
| Cast and Catch | background, bobber, dock, rod, sun, cloud, fish by rarity, cover | (2026-10-26) | Rainbow Fish, Old Boot, Pocket Watch, Golden Hook, Message in a Bottle | Water ripples |
| Match Three | background, board, pieces 1-6, cover | none needed | Pocket Watch (+moves), Prize Bag (bonus), Double Star (next match x2) | Pop sparkle |
| Four in a Row | background, board, player pieces 1-2, team 1-10, cover | none needed | None: no points to change, and a power-up would change who wins | Win line |
| Bubble Pop | background, board, bubbles 1-6, cover | none needed | Bubble Bundle (+bubbles), Prize Bag (bonus), Double Star (next pop x2) | Aim line |
| Bowling | background, lane, ball, pin (now a picture too), team 1-10, cover | pin picture | Golden Pin (roll x2), Prize Bag (bonus), Pin Magnet (one more pin) | Lane lines, strike banner |
| Lunch Rush | wall, counter, team 1-10, cover | food 1-4, guest 1-3 | Extra Plate (+serves), Tip Jar (bonus tips), Double Star (double tips this turn) | Patience hearts, order bubble |
| Question Tracker | background, items 1-6 (stars), cover | none needed | None: each star is one right answer, so extra stars would mislead the teacher | Twinkle dust |
| Big screen (share) | background, lobby picture, winner trophy, cover | new design target | n/a | Leaderboard bars |

Power-ups come after a right answer about a third of the time (items marked
"often" more), never on a wrong one, and the teacher can switch them off in
each game's options. They change points, moves or serves, never the rules.

Later: food names (labels still say pizza, burger...) could take the theme's
own names, like power-ups do.
